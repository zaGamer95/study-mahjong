# study-mahjong — 리치 마작 공부

일본 리치 마작을 **기초부터 고급 전략까지** 정리한 가이드와, 내 손패·버림패를 보고 **어떤 패를 버리는 게 가장 좋은지 이유와 함께 추천**해 주는 버림패 추천기입니다.

빌드 과정이 없는 정적 웹사이트라서 GitHub Pages나 로컬 서버에서 바로 열 수 있습니다.

## 버림패 추천기 (`index.html`)

손패 14장(쯔모 후)과 버림패를 입력하면, **손패의 각 패를 버렸을 때**를 모두 계산해서 순위와 이유를 보여줍니다.

- **샨텐 수** — 일반형·치또이쯔·국사무쌍 중 가장 빠른 형태 기준
- **유효패** — 종류와 남은 장수 (버림패·도라 표시패·후로 등 보이는 패는 제외)
- **다음 단계 품질** — 1샨텐이면 "텐파이 시 평균 대기 장수, 양면급 대기 확률", 2샨텐이면 "1샨텐 도달 시 평균 유효패"
- **텐파이 분석** — 대기패, 대기 형태(양면/간짱/변짱/샤보/단기), 대기패별 역과 판수, **후리텐**, 후로 시 **역 없음** 경고
- **가치** — 도라·적도라 손실, 역패 또이쯔 해체, 객풍패 우선 정리
- **수비** — 상대를 "리치/경계"로 설정하면 현물·스지·중스지·반스지·벽(노찬스/원찬스)·자패 보인 장수로 **추정 방총률**을 계산하고, 내 샨텐 수에 따라 공격/신중/베타오리를 판단
- 손패의 각 패 위에 **순위 배지**를 표시하고, 후보마다 **+/− 이유 목록**과 1위 대비 차이를 설명
- 현재 상황을 **URL 링크로 공유** 가능

### 입력 표기법

```
123m456p789s11z   → 1·2·3만, 4·5·6통, 7·8·9삭, 동 2장
0m / 0p / 0s      → 적5만 / 적5통 / 적5삭
1z~7z             → 동 남 서 북 백 발 중
후로: 555z 123m   → 면자마다 띄어쓰기
```

## 실행 방법

가이드 페이지는 마크다운을 `fetch`로 읽기 때문에 로컬 서버가 필요합니다 (추천기는 `index.html` 파일을 바로 열어도 동작).

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

GitHub Pages: 저장소 Settings → Pages → Branch `main` / `(root)` 로 설정하면 `https://<user>.github.io/study-mahjong/` 에서 열립니다.

## 테스트

```bash
npm test
```

샨텐·유효패·역 판정·위험도·버림패 추천 로직에 대한 단위 테스트입니다 (Node 20+).

```
js/engine.js      분석 엔진 (브라우저/Node 공용, 의존성 없음)

js/tiles-ui.js    패 렌더링
css/style.css     스타일 (라이트/다크 모드)

```

## 한계

- 방총률은 통계 연구에서 흔히 인용되는 수치를 **단순화한 대략치**입니다. 순목, 테다시/쯔모기리, 상대 성향은 반영하지 않습니다.
- 역 판정은 론 기준이며 리치·일발·멘젠쯔모·해저 같은 상황역, 부(符) 계산은 포함하지 않습니다.
- 점수 상황(오라스 조건, 순위)은 고려하지 않습니다. 이런 판단은 [4. 고급](docs/04-advanced.md)을 참고하세요.
