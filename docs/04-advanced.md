# 4. 고급 — 기대값, 밀기/접기, 순위 전략

> 이 장의 목표: "이 선택이 평균적으로 몇 점 이득인가"라는 기대값 관점으로 판단한다.

## 기대값(EV)으로 생각하기

한 번의 타패 선택은 대략 다음의 합으로 평가할 수 있습니다.

```
EV = 화료율 × 평균 타점  −  방총률 × 평균 실점  +  유국 시 텐파이료 등
```

- **유효패 장수**는 화료율을, **도라·역**은 타점을, **위험도**는 방총률을 좌우한다.
- 분석기의 점수도 이 구조를 단순화한 것: 샨텐 → 유효패 → 다음 단계 형태 → 가치 → (위협 시) 위험도 감점.

### 타점과 속도의 교환

- 도라 1장 ≈ 타점 약 1.3~2배. 유효패 몇 장과 바꿀 가치가 있다.
- 초반(1~6순): **속도(유효패) 우선**, 명백한 타점 차이만 반영.
- 중반 이후: 텐파이 속도가 중요해지고, 형태 선택의 폭은 줄어든다.
- 분석기는 도라 1장을 유효패 약 1.4장 정도의 가치로 계산한다 (도라 버림 시 "타점 손실" 표시).

## 밀기 / 접기 (푸시·폴드) 심화

상대 리치 하나에 대한 대표적인 기준입니다 (자, 중반 기준).

| 내 손 | 무스지 중앙패를 버릴까? |
|---|---|
| 양면 텐파이, 1000~2000점 | 대부분 **민다** |
| 간짱 텐파이, 1000점 | **보통 접는다** (현물로 돌리며 텐파이 유지 시도) |
| 간짱 텐파이, 만관 | **민다** |
| 양면·양면 1샨텐, 만관급 | 한두 장은 민다 |
| 1샨텐, 저타점 | **접는다** |
| 2샨텐 이하 | 거의 항상 접는다 |

추가로 고려할 것:

- **상대가 친**이면 실점이 1.5배 → 더 접는다.
- **두 명 이상 리치**면 위험이 겹친다 → 텐파이가 아니면 거의 무조건 접는다.
- **내가 친**이면 화료 가치가 1.5배 + 연짱 → 더 민다.
- **순목이 늦을수록** 내 화료율이 떨어지므로 접는 쪽으로.

### 돌려치기(마와시)

접으면서도 화료나 텐파이를 포기하지 않는 기술.

- 1샨텐에서 위험패 대신 **현물·스지를 버려 형태를 유지**하거나 한 단계 늦춘다.
- 유국 직전 **형식 텐파이**를 노려 노텐 벌점(최대 -3000)을 피한다.

## 상대의 텐파이 읽기

- **테다시 vs 쯔모기리**: 손에서 버리는지, 가져온 패를 바로 버리는지. 중반 이후 테다시가 이어지면 형태가 정리되고 있다는 신호.
- **조기 외측패**: 초반에 `t:1m` `t:9p` 처럼 바깥 패를 버린 사람은 중앙 패를 모으고 있다 → 그 수트의 **안쪽 무스지**가 위험.
- **리치 선언패 주변**: 리치 선언패의 옆·스지 근처(예: `t:5p` 선언 → `t:2p`, `t:8p` 은 스지지만, `t:4p`·`t:6p` 근처 간짱/양면 조합 주의).
- **후로자**: 역패 퐁 + 도라 없음 → 저타점 빠른 화료 목표. 혼일색 후로 → 그 수트와 자패가 위험.
- **도라 주변**: 상대가 도라를 끼고 있을 가능성이 높으니 도라와 그 옆 패는 더 위험하다.

## 수비 테크닉 심화

| 우선순위 | 패 | 비고 |
|---|---|---|
| 1 | 현물 | 모든 리치자에게 현물인 패가 최우선 |
| 2 | 3장 보인 자패 | 단기만 가능 |
| 3 | 스지 1·9, 2장 보인 자패 | |
| 4 | 노찬스 벽 패 | 양면이 불가능한 패 |
| 5 | 스지 2·8, 중스지 4·5·6 | |
| 6 | 스지 3·7, 원찬스 | |
| 7 | 생패 자패, 무스지 1·9 | |
| 8 | 반스지·무스지 중앙패 | 가장 위험 |

- 여러 명이 리치면 **공통 현물**부터.
- 안전패를 버리는 **순서**도 중요: 나중에 필요할 안전패(여러 명에게 안전한 패)를 아껴 둔다.
- 1장만 남은 안전패보다 **여러 순 버틸 수 있는 또이쯔·커쯔 안전패**가 가치 있다.

## 순위 전략 (오라스와 점수 상황)

온라인 랭크전(작혼·천봉 등)은 **순위**가 점수보다 중요합니다.

- **4등 회피**: 랭크 포인트에서 4등 감점이 가장 크다 → 3등 이상 확보가 최우선.
- **오라스 조건 계산**: 역전에 필요한 화료 점수(쯔모/직격 론/타인 론)를 반드시 계산하고, 조건에 맞지 않는 화료는 하지 않는다(앗가리 야메 등 규칙 확인).
- **1등의 오라스**: 빠른 화료로 게임을 끝내는 것이 최선. 무리한 타점 추구 금지.
- **점수 차가 작을 때**: 노텐 벌점 1000~3000점도 순위를 바꾼다 → 형식 텐파이 가치 상승.

### 오라스 예시

> 남4국, 나는 3등이고 2등과 3,500점 차이. 2등에게 직격하면 점수 차가 2배로 줄어든다.
> - 자 30부 2판 론(2,000점) 직격 → 2,000 × 2 = 4,000점 역전 → OK
> - 다른 사람에게서 론(2,000점) → 역전 불가 → 3,900점 이상 필요

## 리치 판단 심화

- **추격 리치**: 선제 리치자가 있어도 양면 이상이면 대부분 추격하는 것이 기대값이 높다.
- **다마의 이점**: 만관 확정 다마, 친의 고타점 다마, 오라스에서 조건을 이미 만족하는 경우.
- **악대기 리치**: 나쁜 대기도 "상대를 접게 만드는 효과" 때문에 선제라면 리치가 우세한 경우가 많다. 단, 자패 단기나 보이는 패가 많은 대기는 예외.
- **리치 vs 다마 비교**: 리치를 걸었을 때 오르는 타점(1판 + 우라·일발)과, 걸지 않았을 때 늘어나는 화료율·수비력을 비교한다.

## 패효율 심화

- **쿠첸(형태 개선) 우선**: 텐파이보다 좋은 형태를 우선하는 판단. 예: 간짱 텐파이를 거부하고 양면 1샨텐을 유지.
- **안전패 보유**: 중반 이후 1샨텐에서 고립 자패를 **안전패로 들고 가는 것**이 유효패 1~2장보다 가치 있을 때가 있다.
- **타점 확보형 타패**: 탕야오를 위해 1·9를 먼저 버리거나, 삼색·일기통관 가능성을 보고 형태를 선택.

> 분석기가 순수 유효패 기준으로 계산한 결과와 이런 고급 판단이 다를 수 있습니다. 분석기의 "이유" 목록을 보고 **왜 다른지**를 생각해 보는 것이 가장 좋은 공부입니다.
