# 5. 족보 — 역(役) 일람

> 표기: **멘젠 / 후로** 판수. "멘젠 한정"은 울면 성립하지 않는다. "−1"은 울면 1판 줄어드는 역(쿠이사가리).
> 규칙은 일본 프로 리그·온라인(작혼·천봉)에서 널리 쓰는 **쿠이탕 있음, 적도라 3장** 기준입니다.

## 1판 역

| 역 | 멘젠 / 후로 | 조건 | 예시 |
|---|---|---|---|
| 리치 (立直) | 1 / – | 멘젠 텐파이 시 1000점을 걸고 선언 | |
| 일발 (一発) | 1 / – | 리치 후 1순 이내 화료 (도중 울기가 있으면 무효) | |
| 멘젠쯔모 (門前清自摸和) | 1 / – | 멘젠으로 쯔모 화료 | |
| 탕야오 (断么九) | 1 / 1 | 2~8의 수패만 사용 | `t:234m 567p 345s 678s 22p` |
| 핑후 (平和) | 1 / – | 슌쯔 4개 + 역패가 아닌 머리 + **양면 대기** | `t:123m 456p 789s 34s 55m` (2·5삭 대기) |
| 이페코 (一盃口) | 1 / – | 같은 슌쯔 2개 | `t:223344m` |
| 역패 삼원패 | 1 / 1 | 백·발·중 커쯔 (각 1판) | `t:555z` |
| 역패 자풍 | 1 / 1 | 자기 자리 바람 커쯔 | 남가라면 `t:222z` |
| 역패 장풍 | 1 / 1 | 판의 바람 커쯔 (동장 = 동) | `t:111z` |
| 영상개화 (嶺上開花) | 1 / 1 | 깡 후 영상패로 쯔모 화료 | |
| 창깡 (搶槓) | 1 / 1 | 남의 가깡 패로 론 | |
| 해저로월 (海底撈月) | 1 / 1 | 마지막 패로 쯔모 화료 | |
| 하저로어 (河底撈魚) | 1 / 1 | 마지막 버림패로 론 화료 | |

> **더블 동 / 더블 남**: 동장의 동가가 동 커쯔 → 장풍 + 자풍 = 2판.

## 2판 역

| 역 | 멘젠 / 후로 | 조건 | 예시 |
|---|---|---|---|
| 더블 리치 | 2 / – | 첫 순에 리치 (그 전에 울기 없음) | |
| 삼색동순 (三色同順) | 2 / 1 | 만·통·삭 같은 숫자의 슌쯔 | `t:234m 234p 234s` |
| 일기통관 (一気通貫) | 2 / 1 | 한 수트로 123·456·789 | `t:123456789p` |
| 찬타 (混全帯么九) | 2 / 1 | 모든 면자·머리에 요구패 포함, 자패 있음 | `t:123m 789p 999s 111z 99m` |
| 치또이쯔 (七対子) | 2 / – | 또이쯔 7개 (25부 고정) | `t:1133m 5577p 22s 66s 77z` |
| 또이또이 (対々和) | 2 / 2 | 커쯔 4개 | `t:222m 777p 999s 555z 11z` |
| 산안커 (三暗刻) | 2 / 2 | 스스로 만든 커쯔 3개 | |
| 삼색동각 (三色同刻) | 2 / 2 | 만·통·삭 같은 숫자의 커쯔 | `t:555m 555p 555s` |
| 산깡쯔 (三槓子) | 2 / 2 | 깡 3개 | |
| 소삼원 (小三元) | 2 / 2 | 삼원패 커쯔 2개 + 삼원패 머리 (역패 2판 추가로 사실상 4판) | `t:555z 666z 77z` |
| 혼노두 (混老頭) | 2 / 2 | 요구패만 사용 (또이또이 또는 치또이와 복합) | `t:111m 999p 111z 222z 99s` |

## 3판 역

| 역 | 멘젠 / 후로 | 조건 | 예시 |
|---|---|---|---|
| 혼일색 (混一色) | 3 / 2 | 한 수트 + 자패 | `t:123345789s 555z 11z` |
| 준찬타 (純全帯么九) | 3 / 2 | 모든 면자·머리에 노두패, 자패 없음 | `t:123m 789m 123p 999s 11s` |
| 량페코 (二盃口) | 3 / – | 이페코 2개 (치또이로 보지 않음) | `t:223344m 556677p 99s` |

## 6판 역

| 역 | 멘젠 / 후로 | 조건 | 예시 |
|---|---|---|---|
| 청일색 (清一色) | 6 / 5 | 한 수트만 사용 | `t:11123455678999m` |

## 역만 (役満)

| 역 | 조건 |
|---|---|
| 국사무쌍 (国士無双) | 13종 요구패 + 그중 1장 더. 13면 대기는 더블역만인 규칙도 있음 |
| 스안커 (四暗刻) | 스스로 만든 커쯔 4개. 샤보 대기 론은 산안커+또이또이로 떨어짐. 단기 대기는 더블역만 규칙도 있음 |
| 대삼원 (大三元) | 백·발·중 모두 커쯔 |
| 자일색 (字一色) | 자패만 사용 |
| 녹일색 (緑一色) | 2·3·4·6·8삭 + 발만 사용 |
| 청노두 (清老頭) | 노두패(1·9)만 사용 |
| 소사희 (小四喜) | 풍패 커쯔 3개 + 풍패 머리 |
| 대사희 (大四喜) | 풍패 커쯔 4개 (더블역만 규칙도 있음) |
| 구련보등 (九蓮宝燈) | 한 수트로 1112345678999 + 1장, 멘젠 한정 |
| 스깡쯔 (四槓子) | 깡 4개 |
| 천화 (天和) | 친이 배패 14장으로 바로 화료 |
| 지화 (地和) | 자가 첫 쯔모로 화료 (그 전에 울기 없음) |

## 역이 아닌 것 (판수만 추가)

| 항목 | 판수 |
|---|---|
| 도라 | 1장당 1판 |
| 적도라 | 1장당 1판 |
| 우라도라 | 리치 화료 시, 1장당 1판 |
| 북도라 | 3인 마작만 |

> 도라만으로는 화료할 수 없습니다. 반드시 역이 1개 이상 필요합니다.

## 자주 헷갈리는 포인트

- **핑후 조건 4가지**: ① 멘젠 ② 슌쯔 4개 ③ 머리가 역패가 아님 ④ 양면 대기. `t:12m` 로 3만을 기다리는 변짱이나 간짱은 안 된다.
- **쿠이탕**: 울어도 탕야오 성립(대부분 온라인 규칙). 일부 친선 규칙에선 불가.
- **찬타와 준찬타**: 자패가 하나라도 있으면 찬타, 없으면 준찬타.
- **혼일색 + 역패 + 도라**는 후로로도 만관을 만들기 쉬운 대표 조합.
- **치또이쯔는 같은 패 4장을 2쌍으로 쓸 수 없다**.
- **역 없음 텐파이**: 울었는데 역이 없다면 형식 텐파이(유국 시 텐파이료)만 가능. 분석기는 이런 텐파이를 "역 없음"으로 표시한다.

## 분석기가 인식하는 역

버림패 추천기는 텐파이 시 대기패별로 다음 역을 자동 확인합니다 (론 기준, 리치/일발/멘젠쯔모 등 상황역 제외):

탕야오, 핑후, 이페코, 량페코, 역패(삼원패·자풍·장풍), 삼색동순, 삼색동각, 일기통관, 찬타, 준찬타, 또이또이, 산안커, 소삼원, 혼노두, 혼일색, 청일색, 치또이쯔, 국사무쌍, 스안커, 대삼원, 자일색, 청노두, 소사희, 대사희 + 도라·적도라 개수
