# 1. 기초 — 리치 마작의 규칙

> 이 장의 목표: 패를 읽고, 화료(아가리)의 형태를 이해하고, 한 판이 어떻게 흘러가는지 안다.

## 패의 종류 (총 136장)

같은 패가 **4장씩** 있습니다. 34종 × 4장 = 136장.

| 분류 | 패 | 표기 | 비고 |
|---|---|---|---|
| 만수 (萬子) | 1만 ~ 9만 | `1m`~`9m` | `t:123456789m` |
| 통수 (筒子) | 1통 ~ 9통 | `1p`~`9p` | `t:123456789p` |
| 삭수 (索子) | 1삭 ~ 9삭 | `1s`~`9s` | `t:123456789s` |
| 풍패 (風牌) | 동·남·서·북 | `1z`~`4z` | `t:1234z` |
| 삼원패 (三元牌) | 백·발·중 | `5z`~`7z` | `t:567z` |

- **수패**: 만·통·삭. 숫자가 있어 슌쯔(연속)를 만들 수 있다.
- **자패**: 풍패 + 삼원패. 슌쯔를 만들 수 없고 같은 패끼리만 모인다.
- **노두패**: 1과 9. **요구패**: 노두패 + 자패 (`t:19m19p19s1234567z`).
- **중장패**: 2~8의 수패.
- **적도라(아카도라)**: 대부분의 온라인/대회 규칙에서 5만·5통·5삭 중 한 장씩이 빨간색이며, 가지고 있으면 도라 1개로 친다. 이 사이트에서는 `0m/0p/0s` 로 표기한다.

> 이 저장소의 표기법: 숫자 뒤에 수트 문자. `123m456p789s11z` = 1·2·3만, 4·5·6통, 7·8·9삭, 동 2장.

## 화료(아가리)의 기본 형태: 4면자 + 1머리

손패는 항상 **13장**이고, 1장을 가져와(쯔모) 14장이 되면 1장을 버립니다. 14장이 아래 형태가 되면 화료입니다.

- **면자(멘쯔) 4개** + **머리(작두) 1개**
  - **슌쯔**: 같은 수트의 연속된 3장 `t:345p`
  - **커쯔**: 같은 패 3장 `t:777s`
  - **머리**: 같은 패 2장 `t:55z`

예) `t:123m 456p 789s 555z 11z` → 면자 4개 + 머리 1개 = 화료형

### 예외 형태 2가지

- **치또이쯔(七対子)**: 서로 다른 또이쯔(2장) 7개. `t:11m 33m 55p 77p 22s 66s 44z`
- **국사무쌍(国士無双)**: 13종의 요구패를 한 장씩 + 그중 하나 더. 역만.

## 역(役)이 없으면 화료할 수 없다

리치 마작의 가장 중요한 규칙입니다. 형태가 완성되어도 **최소 1판짜리 역**이 있어야 화료할 수 있습니다.
초보자가 가장 쉽게 만드는 역은 다음 셋입니다.

1. **리치** — 멘젠(울지 않은 상태)으로 텐파이하면 1000점을 걸고 선언. 가장 기본.
2. **탕야오** — 2~8의 수패만으로 완성. 울어도 된다(쿠이탕 있음 규칙 기준).
3. **역패** — 삼원패(백·발·중), 자기 자리 바람(자풍), 판의 바람(장풍)을 커쯔로 모은다.

족보 전체는 [5장 족보](guide.html?doc=05-yaku) 를 참고하세요.

## 한 판의 흐름

1. **배패**: 각자 13장(친은 14장)을 받는다.
2. **쯔모 → 타패**: 반시계 방향으로 돌아가며 패산에서 1장을 가져오고 1장을 버린다.
3. **울기(후로)**: 다른 사람이 버린 패를 가져와 면자를 만든다.
   - **치**: 바로 왼쪽 사람(상가)의 버림패로만 슌쯔를 만든다.
   - **퐁**: 누구의 버림패로든 커쯔를 만든다.
   - **깡**: 같은 패 4장. 영상패(린샨)를 1장 가져오고 도라 표시패가 1장 더 열린다.
4. **화료**
   - **쯔모**: 스스로 가져온 패로 완성 → 세 사람이 나눠서 지불.
   - **론**: 남이 버린 패로 완성 → 그 패를 버린 사람(방총자)이 전부 지불.
5. **유국**: 패산이 다 떨어지면 텐파이한 사람이 노텐인 사람에게 합계 3000점을 받는다(노텐 벌점).

### 자리 이름

| 이름 | 위치 | 설명 |
|---|---|---|
| 하가 (下家) | 오른쪽 | 내 다음 차례 |
| 대가 (対面) | 맞은편 | |
| 상가 (上家) | 왼쪽 | 내 바로 앞 차례. 이 사람의 패만 **치** 가능 |
| 친 (親) | 동가 | 점수를 1.5배로 받고, 화료·텐파이하면 연장(연짱) |

## 게임 길이

- **동풍전**: 동1국 ~ 동4국 (각자 친을 한 번씩)
- **반장전**: 동1국 ~ 남4국 (각자 친을 두 번씩) — 가장 일반적
- 시작 점수는 보통 **25,000점**, 1등 기준 30,000점(오카).

## 멘젠과 후로

- **멘젠(門前)**: 한 번도 울지 않은 상태. 리치를 걸 수 있고, 멘젠 한정 역(핑후, 이페코, 멘젠쯔모 등)을 받을 수 있다.
- **후로(副露)**: 한 번이라도 치/퐁/밍깡을 한 상태. 리치를 걸 수 없고, 일부 역은 판수가 1 줄어든다(쿠이사가리).

## 후리텐 — 론할 수 없는 상태

다음 경우엔 **론을 할 수 없고 쯔모로만** 화료할 수 있습니다.

1. **버림패 후리텐**: 내 대기패 중 하나라도 **내가 이미 버린 적이 있을 때**.
2. **동순 후리텐**: 같은 순목에 대기패가 나왔는데 론하지 않고 넘겼을 때 (다음 내 쯔모까지).
3. **리치 후 후리텐**: 리치 후 대기패를 놓치면 그 판 내내 론 불가.

예) `t:23p` 양면으로 1통·4통 대기인데 예전에 1통을 버렸다 → 4통이 나와도 론 불가.
분석기는 **내 버림패**를 입력하면 후리텐을 자동으로 경고합니다.

## 도라

- 패산의 **도라 표시패** 다음 패가 도라. 도라 1장당 1판 추가(역은 아님).
- 순서: 1→2→…→9→1 / 동→남→서→북→동 / 백→발→중→백
- 예) 표시패 `t:9m` → 도라 `t:1m`, 표시패 `t:4z` (북) → 도라 `t:1z` (동)
- **우라도라**: 리치를 걸고 화료하면 도라 표시패 아래 패도 표시패가 된다.

## 기본 용어집

| 용어 | 뜻 |
|---|---|
| 샨텐 | 텐파이까지 남은 패의 수. 0샨텐 = 텐파이 |
| 텐파이 | 1장만 더 오면 화료할 수 있는 상태 |
| 유효패 (우케이레) | 가져오면 샨텐 수가 줄어드는 패 |
| 탑쯔 | 1장만 더 오면 면자가 되는 2장 (`t:34m` 양면, `t:35m` 간짱, `t:12m` 변짱) |
| 또이쯔 | 같은 패 2장 |
| 현물 | 리치한 사람이 이미 버린 패. 그 사람에게는 절대 론당하지 않는다 |
| 방총 (放銃) | 내가 버린 패로 남이 론 화료하는 것 |
| 베타오리 | 화료를 포기하고 안전패만 버리는 수비 |
| 다마텐 | 텐파이인데 리치를 걸지 않고 조용히 기다리는 것 |
| 오라스 | 마지막 국 (남4국 등) |
