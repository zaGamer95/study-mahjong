# 2. 초급 — 패효율과 기본 판단

> 이 장의 목표: "무엇을 버릴까"에 대한 기본 원칙을 몸에 익히고, 리치와 수비의 기초를 안다.

## 샨텐과 유효패

- **샨텐 수**: 텐파이까지 필요한 최소 교환 횟수. 1샨텐 = 1장만 잘 들어오면 텐파이.
- **유효패**: 뽑았을 때 샨텐 수가 줄어드는 패. **종류 수 × 남은 장수**로 센다.

패효율의 기본 목표는 단순합니다.

> **샨텐 수를 유지하면서, 유효패가 가장 많이 남는 패를 버린다.**

분석기(버림패 추천기)는 이 계산을 모든 패에 대해 해 주고, 이미 버려지거나 보이는 패는 남은 장수에서 뺍니다.

## 버리는 순서의 기본

첫 몇 순은 고립패(주변과 연결이 없는 패)부터 정리합니다. 가치가 낮은 순으로:

1. **객풍패** — 자풍도 장풍도 아닌 바람패. 커쯔가 되어도 역이 없다.
2. **이미 나온 자패** — 2장 이상 보인 자패는 또이쯔·커쯔가 되기 어렵다.
3. **노두패 (1·9)** — 슌쯔를 만드는 방법이 한 가지뿐.
4. **역패 (삼원패·자풍·장풍)** — 겹치면 1판이 되므로 객풍보다 늦게.
5. **2·8** → **3~7** 순서.

예) `t:13m 457p 2346s 155z 9p` + 동장 동가라면, 동(더블 동)은 역패라 늦게 버리고 고립에 가까운 패부터 정리.

### 왜 1·9가 2~8보다 약할까?

- `t:5m` 에 붙는 패: 3·4·6·7만 → 양면·간짱 여러 가지
- `t:1m` 에 붙는 패: 2·3만 → 변짱·간짱뿐

**연결될 수 있는 패의 수**가 중앙 패일수록 많기 때문입니다.

## 탑쯔의 우열

| 형태 | 예 | 대기 | 유효패 최대 |
|---|---|---|---|
| 양면 | `t:34m` | 2만·5만 | 8장 |
| 간짱 | `t:35m` | 4만 | 4장 |
| 변짱 | `t:12m` | 3만 | 4장 |
| 또이쯔 | `t:55m` | 5만 | 2장 |

→ **양면 > 간짱 ≥ 변짱 > 또이쯔(면자 후보로서)**. 탑쯔를 하나 버려야 한다면 약한 쪽부터.

## 면자는 깨지 않는다

완성된 슌쯔·커쯔를 깨는 것은 대부분 손해입니다. 분석기에서 "슌쯔(몸통)의 일부"라고 나오는 패를 버리는 선택이 낮은 순위라면 그 때문입니다.

## 리치 판단의 기초

멘젠으로 텐파이하면 **기본적으로 리치**를 겁니다.

- 리치만으로 1판 + 일발·우라도라·멘젠쯔모 기회
- 상대가 수비하게 만들어 방총 위험을 떠넘긴다

다만 리치 후에는 **손패를 바꿀 수 없고**, 무조건 쯔모한 패를 버려야 합니다(대기 유지 깡 제외).

### 다마텐을 고려하는 경우 (초급 기준)

- 이미 역이 있고 타점이 충분할 때 (예: 탕야오 + 도라 2 → 다마로도 만관 근처)
- 대기가 너무 나쁘고, 곧 좋은 형태로 바꿀 수 있을 때 (텐파이 변경)

## 울기(후로)의 기본

초급 단계에서는 **"역이 확정되는 울기만 한다"** 를 지키세요.

- 역패 또이쯔를 퐁 → 역패 확정. OK
- 탕야오 형태(요구패 없음)에서 치/퐁 → OK
- 역이 없는데 운다 → **역 없음**으로 화료 불가. 분석기는 이런 텐파이에 "역 없음" 경고를 띄운다.

## 수비의 기초: 현물을 버려라

상대가 리치했고 내 손이 좋지 않다면(2샨텐 이상) **베타오리**가 기본입니다.

1. **현물**: 리치한 사람이 버린 패 → 그 사람에게 100% 안전.
2. **리치 후 다른 사람이 버린 패가 통과한 것** → 역시 그 리치자에게 현물.
3. 현물이 없으면 **자패 중 여러 장 보인 것**, 그다음 **스지** (중급에서 자세히).

> 분석기의 상대 칸에서 "리치"를 선택하면, 각 패의 위험도와 함께 공격/수비 판단을 알려줍니다.
