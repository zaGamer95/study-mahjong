# 3. 중급 — 형태, 리치 판단, 스지·벽

> 이 장의 목표: 유효패 "장수"를 넘어 "형태의 질"을 보고, 상대 버림패로 위험도를 추정한다.

## 5블록 이론

화료에는 면자 4개 + 머리 1개 = **5개의 블록**이 필요합니다. 손패를 블록 단위로 세어 보세요.

- 블록이 **6개 이상**이면 넘친다 → 가장 약한 블록(변짱, 간짱, 고립 또이쯔)을 정리한다.
- 블록이 **5개 이하**라면 → 고립패 중 연결 가능성이 높은 패(3~7)를 남겨 블록을 만든다.

예) `t:23m 46m 57p 34s 678s 99s 1z` → 23m / 46m / 57p / 34s / 678s / 99s = 6블록. 5개로 줄이려면 가장 약한 간짱(`t:46m` 또는 `t:57p`)을 정리한다.

## 좋은 복합형 (외워 두면 강해지는 형태)

| 형태 | 예 | 받는 패 | 설명 |
|---|---|---|---|
| 삼면 대기 | `t:23456m` | 1·4·7만 | 텐파이 형태 중 최강급 (최대 11장) |
| 노베탄 | `t:3456s` | 3·6삭 | 면자+단기 두 가지로 해석되는 텐파이 형태 |
| 량칸 | `t:135m` | 2·4만 | 간짱 두 개가 겹쳐 양면과 같은 8장 |
| 양면·양면 1샨텐 | 몸통 2개 + `t:34m 67p 55s` + 여분 1장 | 2·5만, 5·8통 (16장) | 어떤 유효패가 와도 양면 텐파이가 된다 |

> 분석기의 **"텐파이 시 평균 대기 장수"** 와 **"2종 이상 대기 확률"** 은 이 "형태의 질"을 숫자로 보여줍니다. 유효패 장수가 같다면 이 값이 높은 쪽을 고르세요.

## 1샨텐에서의 선택

1샨텐에서는 **유효패 장수**보다 **텐파이했을 때 대기가 좋은가**가 더 중요해지는 경우가 많습니다.

- 양면·양면 1샨텐: 몸통 2개 + 양면 2개 + 머리 → 어떤 유효패로 텐파이해도 양면 대기 (분석기 기준 양면급 확률 100%)
- 유효패는 많지만 텐파이 시 간짱·변짱이 남는 형태 → 좋지 않음

## 리치 판단 (중급)

| 상황 | 판단 |
|---|---|
| 양면 이상 대기, 선제(아무도 리치 안 함) | **즉시 리치** (거의 항상) |
| 간짱/변짱 대기, 선제, 타점 낮음 | 리치 OK (나쁜 대기 선제 리치도 기대값 플러스인 경우가 많다) |
| 역 있음 + 만관 이상 확정 | 다마도 유력 (리치하면 나오지 않는다) |
| 형태 변화 여지가 큼 (쿠첸 우선형), 순목이 이름 | 한두 순 기다렸다 좋은 형태로 리치 |
| 남이 먼저 리치 (추격 리치) | 양면 이상이거나 타점이 높으면 추격, 나쁜 대기 저타점은 신중 |

## 후로 판단 (중급)

- **역패 또이쯔**: 1퐁은 대부분 OK. 특히 도라가 있거나 형태가 나쁠 때.
- **탕야오**: 3샨텐 이상에서의 무리한 울기는 손패가 짧아져 수비력이 약해진다.
- **혼일색/토이토이**: 타점이 확실할 때만. 버림패로 노골적으로 드러난다.
- 울 때마다 손패는 3장씩 줄어든다 → **안전패를 품을 공간이 줄어든다**는 점을 기억.

## 수비: 스지와 벽

### 스지(筋)

양면 대기는 항상 **3칸 차이 두 패**를 기다립니다: 1-4, 2-5, 3-6, 4-7, 5-8, 6-9.
리치자가 `t:4m` 을 버렸다면, 1-4만 양면 대기는 **후리텐이라 불가능** → 1만·7만의 양면 위험이 줄어든다.

| 리치자가 버린 패 | 스지가 되는 패 |
|---|---|
| 4 | 1, 7 |
| 5 | 2, 8 |
| 6 | 3, 9 |
| 1과 7 | 4 (중스지) |
| 2와 8 | 5 (중스지) |
| 3과 9 | 6 (중스지) |

- **1·9·2·8·3·7**: 한쪽 스지만 있으면 스지.
- **4·5·6**: 양쪽 모두 나와야 **중스지**. 한쪽만이면 **반스지**.
- 스지는 **양면만** 막는다. 간짱·샤보·단기·변짱은 여전히 맞을 수 있다.

### 대략적인 방총률 (리치 상대, 1발 기준)

| 패 | 대략 방총률 |
|---|---|
| 현물 | 0% |
| 3장 보인 자패 | 약 1% 미만 |
| 스지 1·9 | 약 2% |
| 스지 2·8 | 약 3% |
| 중스지 4·5·6 | 약 3~4% |
| 스지 3·7 | 약 4~5% |
| 생패 자패 | 약 6~8% |
| 무스지 1·9 | 약 5~6% |
| 무스지 2·8 | 약 7~8% |
| 반스지 4·5·6 | 약 7~8% |
| 무스지 3·7 | 약 9% |
| 무스지 4·5·6 | **약 12%** |

> 수치는 여러 통계 연구를 단순화한 대략치이며, 분석기 위험도 계산에도 이 표를 사용합니다. 순목·도라·상대 버림패 성향에 따라 달라집니다.

### 벽(카베)과 노찬스·원찬스

- 예: `t:8p` 가 4장 모두 보인다(내 손패 포함) → 9통을 기다리는 양면은 `t:78p` 뿐인데 8통이 없으니 **불가능**. 9통은 샤보·단기에만 맞는다.
- 이렇게 **"어떤 패를 기다리는 양면이 만들어지는 데 필요한 패가 전부 보였다"** → **노찬스**. 1장만 남았으면 **원찬스** (위험도가 꽤 줄어듦).
- 분석기는 버린 패·내 손패·도라 표시패를 모두 합쳐 벽을 계산합니다.

## 공격과 수비 판단 (기초 수치)

상대 리치에 대해, 내 상태에 따른 기본 방침:

| 내 상태 | 방침 |
|---|---|
| 양면 텐파이 or 만관 이상 텐파이 | **밀기**: 무스지도 대부분 버린다 |
| 나쁜 대기 + 저타점 텐파이 | 안전한 패면 밀고, 매우 위험한 패면 접기 고려 |
| 좋은 1샨텐 | 스지·자패 정도는 밀고, 무스지 중앙패는 접는다 |
| 2샨텐 이상 | **베타오리** |

분석기는 이 방침에 따라 위험도 감점의 크기를 바꿉니다. 1샨텐에서 위험패를 버려야만 샨텐이 유지된다면, 한 단계 늦추더라도 안전한 패로 **돌려치기(마와시)** 를 추천할 수 있습니다.

## 점수 계산 맛보기: 부(符)와 판(翻)

점수 = 부 × 2^(판+2) × (친 6배 / 자 4배), 100점 단위 올림.

- 기본은 **30부** (멘젠 론 30부, 핑후 쯔모 20부 등).
- 판이 많아지면 부와 상관없이 **만관(5판)** 이상으로 고정된다.

| 자(子) 론 | 1판 | 2판 | 3판 | 4판 |
|---|---|---|---|---|
| 30부 | 1,000 | 2,000 | 3,900 | 7,700 |
| 40부 | 1,300 | 2,600 | 5,200 | 8,000 (만관) |

| 등급 | 판수 | 자 | 친 |
|---|---|---|---|
| 만관 | 5 (또는 4판 40부↑, 3판 70부↑) | 8,000 | 12,000 |
| 하네만 | 6~7 | 12,000 | 18,000 |
| 배만 | 8~10 | 16,000 | 24,000 |
| 삼배만 | 11~12 | 24,000 | 36,000 |
| 역만 | 13 / 역만 역 | 32,000 | 48,000 |
